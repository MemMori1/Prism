# Prism

> 多引擎 AI 编码 Agent 指挥台 —— 把不同引擎的会话收进同一面墙：浏览历史、发指令、执行中插话、权限审批，都在一处。

Tauri 2 + Vue 3 + Rust 桌面应用（macOS）。四路引擎收进同一套中立事件模型：三路驱动各家官方 CLI / 本地服务，一路（Prism 原生）是内置 Agent，用自己的 API Key 直连模型。引擎原始数据**架构级只读**，Prism 自有数据只写 `~/.prism/`。

## 引擎支持

| 能力 | OpenCode | Codex | Claude Code | Prism 原生 |
|---|---|---|---|---|
| 历史浏览（项目 / 会话 / 时间线 / 工具详情） | ✅ | ✅ | ✅ | ✅ |
| 发消息 · 流式渲染 | ✅ | ✅ | —（待本机 CLI） | ✅ |
| 打断当前回合 | ✅ | ✅ | — | ✅ |
| 执行中插话（排队下一轮） | ✅ | ✅ | — | — |
| 权限审批卡片（一次 / 总是 / 拒绝） | ✅ | ✅ | — | —（仅工作目录守卫） |
| 新建会话（模型 · 推理档位 · 首条指令） | ✅ | ✅ | 灰显并注明原因 | ✅ |
| 用量 / 成本统计 | ✅ | ✅ | ✅ | —（会话内记 token） |
| 订阅配额实时值 | — | ✅ | 待 CLI | — |
| 工坊资产 / MCP 浏览 | ✅ | ✅ | ✅ | 不适用 |

- **OpenCode**：`opencode-cli serve`（HTTP + SSE），惰性启动 + 看门狗回收。
- **Codex**：`codex app-server`（JSON-RPC），配置完全继承 `~/.codex/config.toml`，Prism 不写入不覆盖。
- **Claude Code**：`~/.claude/projects` 档案只读解析；运行轴等本机装好 `claude` 后再接。
- **Prism 原生**：不依赖任何本机 CLI，内置 Agent 循环直连 OpenAI 兼容端点；模型与密钥在设置里自管，详见下一节。

## 内置 Agent（Prism 原生）

新建会话的第一张卡片就是它，图标与强调色单列，和另外三家区分开；还没配 API 时点开直接进配置。上次用过的那张卡片会标「上次使用」。

**模型服务**（设置 → 模型）：可以挂多个 OpenAI 兼容服务，各自一份 `baseUrl` + 密钥 + 勾选过的模型，内置 DeepSeek / OpenAI / Ollama 预设。
- 模型列表可从 `/models` 拉取（认 `{data:[…]}`、`{models:[…]}` 与裸数组三种形状），也能手填 id。
- 全局只有一个「当前模型」，切模型不必重填密钥；会话头会回显模型名与所属服务。
- 密钥永不回传给界面，只给 `hasKey` 与末四位；`~/.prism/native/config.json` 落盘 0600。旧版单端点配置自动迁移。

**回合循环**：请求 → 流式收分片（文本 / 推理 / 工具调用各自累积）→ 有 `tool_calls` 就逐个执行 → 结果回填 → 下一轮；模型不再调工具或触及单轮上限（1–40，默认 12）即收尾。事件形状与另外三家对齐，时间线、工具卡、diff 展示全部复用。

**六个本地工具**

| 工具 | 作用 | 约束 |
|---|---|---|
| `read_file` | 读文件（可带行范围） | 默认 2000 行，输出截断 20k 字符 |
| `list_files` | 列目录 | 最多 300 条，跳过 `.git` / `node_modules` / `target` 等 |
| `grep` | 正则搜内容 | 最多 120 条命中，跳过 >1.5MB 的文件 |
| `write_file` | 整文件写入 | 仅工作目录内，自动建父目录 |
| `edit_file` | 按片段替换 | 同上，多命中需显式声明全部替换 |
| `run_command` | 跑本机命令 | 默认 120s 超时，输出截断 |

路径先做词法归一（消掉 `..`），再对最近的已存在祖先 `canonicalize`，因此绕道符号链接也会被判定越界。

**第七个工具：`task`（子代理）**

主代理的清单里除了上面六个本地工具，还多一个 `task`——起一个**隔离上下文的子代理**独立跑子任务，翻多少文件、搜多少关键词都不进主对话，只把一份最终报告带回来。适合大范围探索 / 调研。

| 子代理类型（`agent_type`） | 工具集 | 用途 |
|---|---|---|
| `explore`（默认，认不出即此） | 只读：`read_file` / `list_files` / `grep` | 找代码、读文档、汇总信息 |
| `general` | 六个工具全开，写类照样过权限闸门 | 改文件、跑命令的完整子任务 |

- **扁平编排**：子代理的工具清单里没有 `task`，开不出孙代理。
- **隔离**：自己的消息历史 + 自己的系统提示；过程轨迹（文本片段 + 工具摘要）边跑边经 `session.tool.progress` 推给父级工具卡，报告＝最后一条无工具调用的正文。
- **上限**：最多 16 轮，另有累计 token 软预算（20 万）兜底「花多少」；两者任一触发都会收掉工具声明并追加一句「别再调工具、直接交报告」，逼它把已有信息写成报告，不至于白跑。被强收的报告在工具卡上标「已强收」，提示它没跑完。
- **成本**：子代理烧的 token 计入会话总量；用户点停止时父子一起收手，写类动作与主代理共用同一套权限档位。

**权限档位**（输入框工具行、git 分支右边那一颗）：只读 / 每次询问 / 完全访问，按会话记（新会话沿用上次）。

| 档位 | 行为 |
|---|---|
| 只读 | `write_file` / `edit_file` / `run_command` 直接拒绝，工具卡上写明原因 |
| 每次询问 | 写文件、改文件、跑命令之前弹审批卡（允许一次 / 总是允许 / 拒绝）；「总是允许」按会话 + 动作记住 |
| 完全访问 | 不问，直接执行 |

读类工具（`read_file` / `list_files` / `grep`）不受档位限制——它们本来就被限制在工作目录内。审批走的是和另外两家引擎同一套 `permission.asked` / `session_permission_reply` 契约，所以卡片、通知中心、停止按钮都是现成的；点停止会连等待中的审批一起放掉。档位随每条消息下发，闸门在 Rust 侧执行，界面只是开关。

**存储**：`~/.prism/native/sessions/<id>/`，`meta.json` 存标题 / 目录 / 模型 / 累计 token，`messages.jsonl` 一行一条消息（含工具调用原文）。用 JSONL 是因为只追加、损坏最多丢最后一行，`tail` 就能调试。

**中断**：停止按钮不是摆设——检查点落在发请求前、拿到响应后、每读一行 SSE 时，延迟基本就是一行分片的时间；中断走 `interrupted` 事件，不会显示成报错。

## 功能

八个一级视图，左侧 48px 图标栏切换，顺序可拖拽调整（首页固定置顶）。

**顶栏会话导航** — 标题栏里只有一个入口：`<Agent> 的会话`（跑着 / 待审批的会话带状态点）。点开是两栏面板：左列 Agent（各自最近会话数，当前那个标「当前」），右列才是它的会话——可搜标题与项目、↑↓ 与 Enter 直接开；点会话只让左侧「当前进行的会话」栏对应那条激活，不切多列并排（要并排走每行悬停的 ⇥）。面板底部「＋ 用 X 新建会话」承接换 Agent / 开新的，新页沿用上次用过的目录。

**首页（仪表盘）** — 今日 token 脉搏（含峰值日）与近 7 天合计 · 28 天热力图 · 工作节奏（按会话开始时刻的 24 小时分布）· 模型分布（跨引擎 top 5，占比 + 成本）· 项目活跃（按工作目录合并，点击跳归档）。纯只读统计，复用「用量」后端。

**归档** — 三栏：项目 / 会话 / 时间线，打开即读，零导入。
- 项目列表：引擎徽标、分支、会话数；支持置顶、按名称/路径/分支筛选、右键菜单（置顶 / 复制路径）；同仓多 worktree 自动收组。
- 分支徽标可点开弹层：搜索、↑↓ / Enter / Esc 键盘操作，可直接切分支或从当前 HEAD 新建分支，失败时回原文报错。
- 会话列表：星标、标签（可改名换色）、标题编辑（双击或 ✎）、排序与时间范围筛选、星标筛选。
- 时间线：文本 / 推理 / 工具卡片（按需加载完整输入输出与 diff）/ 权限卡片 / LaTeX / 沙箱化 HTML·SVG / 150 条分页；每轮 token 四联（输入 · 缓存读 · 输出 · 思考）+ 成本 + 上下文用量条；长会话有回底浮标。
- 抽屉「文件」：两栏列表——变更（会话目录相对 HEAD 改了哪些文件：状态 / ± 行数，跑完一轮自动刷新）与全部文件（git 索引优先、尊重 .gitignore，可筛选）。右边三屏：**变更**（unified diff，增删上色）、**预览**（markdown 直接渲染、图片直接显示、代码按 ts/js/vue/rs/py/go/sh/css/json 上色 + 行号）、**编辑**（纯文本编辑，⌘S 保存；只允许会话目录 / 仓库根内的已存在文件）。「打开方式」还能交给系统：默认应用 / 在访达中显示 / 复制路径。另有产物预览（本地 HTML / SVG / 图片，禁脚本禁联网）。
- 三栏宽度可拖拽（键盘 ←/→ 微调，Shift 加倍），双击分隔条复位；每栏都有最小宽度，窗口变窄时按比例收紧而不是把主栏挤没。

**工作台** — 多列并行指挥：一屏盯多个跑着的会话，发送 / 插话 / 停止 / 审批都在列内；列宽可拖、布局持久化；顶部汇总待审批角标。新建会话走两栏页：左挑工作目录、右挑 Agent，Agent 与目录都默认沿用上次的选择；选完先给输入框，**发出第一条消息才真的建会话**——不聊就不会留下没名字的空会话；「＋ 新建会话」每次都回选择器（上次用过的标出来），随时能换 Agent。

**赛马** — 同一问题广播给 1–4 个参赛会话（OpenCode / Codex 任意组合）同时开跑，答案 / 用时 / token / 成本并排对比；最快完成打 🏁；可单列中断、全部停止、同题再跑、一键切回归档。

**搜索** — 本地 FTS5 trigram 索引（`~/.prism/search.db`），中文子串即查即中，两字词回退 LIKE；结果点击定位到消息并短暂高亮。

**用量** — 跨引擎 token 明细（输入 / 输出 / 思考 / 缓存读写）+ 每日柱状曲线 + 按引擎 / 模型分列 + 成本估算（内置价格表，未收录模型标注不计入合计）；顶部「配额（实时）」显示 Codex 订阅窗口进度、重置倒计时与套餐。

**工坊** — 资产只读浏览：技能 / 命令 / 子代理 / 记忆 / 插件 × 三引擎（用户 / 内置 / 项目），markdown 预览 + 系统程序打开；MCP 模式列出三引擎真实配置位置的服务器并探活（仅 http GET，**绝不 spawn stdio**，环境变量只显示键名）。

**自动化** — 定时任务（`~/.prism/routines.json`，五字段 cron）：到点用引擎运行轴跑提示词，执行日志带 sessionId 可回看会话；应用内 30s tick 调度，合盖唤醒按窗口合并补一次。

**贯穿全局**
- 通知：回合完成 / 失败 / 待审批进顶栏铃铛持久面板，非前台时发系统通知（拒绝权限静默降级）。
- 托盘：菜单栏图标带待审批计数、菜单状态行与 tooltip；**关窗 ≠ 退出**（隐藏窗口，定时任务与通知继续跑），Cmd+Q 退出。
- 设置：系统 / 外观 / 模型 / 引擎 / 渠道 / 智能增强 / 扩展能力 / 权限，八个分区。
- 模型管理（设置 → 模型）：多服务并存、预设、拉取模型、密钥脱敏回显、默认模型与单轮上限，见「内置 Agent」一节。
- 自动更新：设置内检查 → 下载 → 重启生效，更新清单走 gh-pages 镜像 + GitHub Releases 兜底。
- 自研控件：下拉、输入框工具条（`+` 命令 / 文件引用 / 模型 / 推理强度 / 发送、`!` 直跑本机 shell）、对话框与按钮统一为同一套视觉与键盘行为。
- 执行中的输入：上一轮没跑完时输入框**照常可用**，Enter 先把这条停在「待发送」卡上（右侧三个按钮：立即发送 / 修改 / 删除，这一轮结束自动发；点停止则退回输入框）。「立即发送」是插话——消息排进引擎队列，在下一步请求模型前接上，不打断正在跑的工具。
- 上下文占用：输入框里一颗小环 + 百分比（口径是最近一轮 input + 缓存读 + 输出，分母优先用引擎给的窗口）。点开看构成——系统提示词 / 工具定义 / 工具结果 / 对话消息各多少 token，分项按字符数占比分摊，总量取自引擎。

## 安装

下载 `Prism_x.y.z_aarch64.dmg`，拖入「应用程序」。未签名版首次打开会被 Gatekeeper 拦下，请在访达里对 Prism **右键 → 打开**（仅需一次）。细节与发版流程见 [docs/RELEASE.md](docs/RELEASE.md)。

## 开发

```bash
pnpm install
pnpm tauri dev     # 开发模式（需要 Rust 工具链）
pnpm test          # 前端单测（vitest）
cd src-tauri && cargo test --lib   # Rust 单测（引擎适配器 / IPC / 工具守卫）
pnpm tauri build   # 打包（macOS：.app + .dmg）
```

```
src/                 Vue 前端；components/ 一组件一文件，样式按组件放 styles/components/
src/*.ts             纯逻辑模块（nav / liveTurn / diff / markdown / format …，多数带单测）
src-tauri/src/       Rust 后端；ipc.rs 是命令入口，engines/{opencode,codex,claude,native} 是四路适配器
docs/                ROADMAP / RELEASE / PLAN
```

## 设计原则

- **数据主权**：引擎原始数据架构级只读；Prism 自有数据只存 `~/.prism/`。
- **适配器架构**：新引擎 = 新适配器，界面零改动。
- **中立事件**：运行时事件统一为中立模型，上层不感知引擎差异。
- **干净房间**：不复制任何第三方应用的代码、文案与视觉资源。

## 已知边界

- 仅 macOS（aarch64）验证与打包；Windows 未支持，未做 Apple 公证。
- Claude Code 目前只有历史浏览，运行轴待本机 CLI。
- 搜索索引当前覆盖 OpenCode 归档，Codex / Claude / Prism 原生尚未纳入。
- Prism 原生：暂无逐条权限审批（只有工作目录守卫 + 命令超时）、无图片/附件输入、不支持执行中排队插话；用量页还未统计原生会话。
- 同一目录会同时出现「外部引擎项目」与「原生项目」两条，尚未按 worktree 合并。
- 图片输入与流式期间的输入排队尚未实现。
- 定时任务需要 Prism 进程在跑（关窗只是隐藏窗口）。

路线图与已完成里程碑见 [docs/ROADMAP.md](docs/ROADMAP.md)。

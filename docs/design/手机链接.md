# 手机链接（phone.link 插件）设计

> 状态：v1 已实现。入口：设置 → 手机链接。本文记录架构、安全边界与扩展位。

## 定位

让手机「连上」桌面的 Prism，两件事：

1. **扫码对话**（主路径）：桌面生成局域网配对二维码 → 手机用微信「扫一扫」或相机打开
   → 对话页直接跑在手机浏览器 / 微信内置浏览器里 → 发消息即驱动桌面 Agent（流式回显、
   权限审批、可中断）。
2. **微信通知推送**（可选）：兼容「群机器人」消息格式的 Webhook（如企业微信群机器人），
   把任务完成 / 权限请求 / 运行出错推到群里。

### 为什么没有「微信聊天窗口里的 bot」

个人微信没有官方机器人接口（腾讯只开放公众号 / 企业微信体系）。所有「普通个人微信
机器人」都是逆向协议方案（web 协议只支持老号、hook 方案需注入客户端），有封号风险且
无法干净地嵌进 Rust 后端。ZCode 的微信 bot 依赖其服务端基础设施，Prism 是纯本地应用。
「微信内置浏览器打开对话页」是普通微信能官方做到的最接近形态。

## 架构

```
┌─ 桌面 (Tauri) ──────────────────────────────┐      ┌─ 手机 ───────────┐
│ settings → PhoneLink.vue ── ipc ──┐         │      │                  │
│                                   ▼         │      │  微信扫一扫       │
│  phone.link 插件                 状态视图    │◀─QR──┐  │       │          │
│  ├ store.rs   ~/.prism/phone-link.json     │      └──┤       ▼          │
│  ├ server.rs  tiny_http 0.0.0.0:15211  ◀───┼─HTTP────┤ 对话页(page.html) │
│  ├ turn.rs    引擎回合 + 事件缓冲(seq)      │         └──────────────────┘
│  ├ push.rs    webhook 推送 ────────────────┼──────────▶ 微信群
│  └ qr.rs      配对二维码 SVG                │
└─────────────────────────────────────────────┘
```

- 插件按内核 `Plugin` trait 装配（`plugins.rs::PhoneLink`，id `phone.link`，
  requires `engine.host`），设置里可见、可停用——与 routines 完全同构。
- 回合走 `Engine` trait（subscribe → create_session → send_prompt → wait_terminal），
  文本归集用「最后一段非空正文是结论」口径（同 DAG 执行器）；工作区固定
  `~/.prism/phone-workspace`（数据主权，不碰用户项目）。
- 手机页是内嵌单文件 `page.html`（include_str!，无构建步骤）：配对 → 长轮询事件流
  （seq 续传）→ 发消息 / 审批权限 / 中断。

## 协议（LAN HTTP，默认端口 15211）

| 路由 | 鉴权 | 说明 |
|---|---|---|
| `GET /`、`GET /p/<token>` | 无 | 同一张页面：无设备令牌时先配对 |
| `POST /api/pair` {token} | 配对码（一次性、2 分钟、限速 10 次/分） | 换设备令牌 |
| `POST /api/message` {text} | 设备令牌 | 跑一轮（互斥，忙时 400） |
| `GET /api/events?since=N` | 设备令牌 | 长轮询（≤20s），返回 seq>N 的事件 + latest |
| `POST /api/permission` {id,decision} | 设备令牌 | once / reject，转发到对应引擎 runtime |
| `POST /api/interrupt` | 设备令牌 | 打断当前回合 |

事件流类型：`status` / `delta` / `tool` / `permission` / `permission_done` /
`turn_end` / `notice`。缓冲 500 条，seq 只增，客户端断线重连用 `since` 续传。

## 安全边界

- 服务仅在本插件启用时监听；停用即关。
- 配对码一次性、120 秒过期、限速；设备令牌 128-bit 随机，请求头校验。
- 配置 `~/.prism/phone-link.json` 0600；webhook 与设备令牌明文落盘（与 native 密钥
  同口径）但**永不回传 UI**（只给「已配置 + 尾 4 位」）。
- 手机回合默认工作区隔离；权限请求不自动放行——转发手机页 + webhook，超时兜底打断。

## 扩展位

- **双向微信回调**（公众号 / 企业微信自建应用）：在 `phone_link` 加一个 `inbound`
  适配器模块即可复用 turn/push，无需动 server 的对话通路；需要公网回调地址。
- **多设备**：`PairedDevice` 目前单条，表结构改成列表即可；长轮询与令牌校验天然支持。
- **更多推送渠道**：`push.rs` 的 `send(webhook, markdown)` 是唯一出口，换格式只动这一处。

# Prism — MVP 计划

> 定位：**多引擎 AI 编码 Agent 指挥台**（从零自研，不基于任何现有项目代码）。

## v0.1 范围（狠砍版）

只做「浏览 + 指挥」一条主线，四个界面：

| 界面 | 内容 | 里程碑 |
|---|---|---|
| 侧栏（项目 / 会话列表） | 读 OpenCode 数据库，零导入自动发现 | M1 |
| 会话视图 | 时间线：文本 / 推理 / 工具卡片；实时流式渲染 | M1（静态）+ M3（流式） |
| 输入框 | 发消息、执行中插话（steer）、中断 | M3 / M4 |
| 设置 | 引擎状态（安装 / 版本 / 健康检查） | M5 |

**v0.1 明确不做**：搜索、赛马、定时任务、小组件、菜单栏、MCP、文件账本、
渠道系统、全景图、多语言（先中文）。

## 里程碑

- [x] **M2** 时间线打磨：工具卡片详情（按需加载输入/输出/错误）、diff 渲染

## 引擎路线

1. **OpenCode 先行**（本机可全程真机测试）
2. Claude Code（只读档案 → stream-json 运行轴）
3. Codex（rollout 档案 → app-server 运行轴）

## 技术栈与结构

Tauri 2 + Vue 3 + TypeScript + Rust。

```
src/                  # 前端（Vue）
  components/         # 界面组件
  engines/            # 前端引擎模型（类型、展示）
  api.ts              # IPC 封装
src-tauri/src/
  engines/            # 引擎适配层（Rust）
    core.rs           # 中立模型（项目 / 会话 / 时间线 / 事件）
    opencode/         # OpenCode 适配器
      locator.rs      # 数据与 CLI 定位
      db.rs           # 只读读取 opencode.db
  ipc.rs              # Tauri 命令
docs/                 # 文档
```

## 决策记录

- **名字**：Prism（棱镜——把多个引擎的光汇成一束统一视角）。
- **引擎顺序**：OpenCode 先行（最快端到端跑通）。
- **许可**：TBD（发布前定；开源或闭源均可，代码全部自研无授权包袱）。
- **增值数据**：存放 `~/.prism/`（如后续加标题 / 标签），引擎原始数据一律只读。
- **干净房间**：界面视觉完全自研，不复制任何现有项目的代码、文案与资源。
